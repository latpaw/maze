# 小小迷宫工坊

一个适合五六岁孩子的中文迷宫生成网页。没有运行时依赖、远程字体、账号或服务器接口，所有生成和导出均在浏览器内完成。

## 打开网页

直接用现代浏览器打开 `index.html` 即可使用，包括 PDF、PNG 下载。也可以在本目录运行：

```sh
npm run dev
```

然后访问 `http://127.0.0.1:4173`。不需要运行 `npm install`。自定义端口使用 `npm run dev -- --port 8080`。

## 已实现

- 11 类、106 种原创轮廓：经典形状、动物、海洋、天空、交通、生活物品、食物、自然、探险、节日。
- 六边形、三角形采用等边三角网格，墙线沿三个方向延伸；圆形采用完整同心圆环与径向通道，从外圈入口走到中心出口。这三类保留几何结构，线条风格选项适用于其他轮廓。
- 一次生成 1～20 道；每道独立选择造型、四档难度、三种玩法。可以搜索形状、批量设置、随机搭配或只重新生成一道。
- 从起点到终点唯一解，所有可用格子连通；收集玩法的三颗星星均在正确路线中。
- 挑战档使用更密的通道；候选筛选同时考虑主路、岔路、死胡同和至少三步深的误导支路。
- 极简排版外边距为 6 mm，行列间隔 3 mm；按造型比例分配行高，最后一行只有一道时自动放大。
- A4 每页 1、2、4、6 道（六题采用两列三行）；逐页预览、临时查看答案、独立答案页、姓名日期、自定义标题与黑白省墨模式。
- 线条支持直线、圆弧和曲线，默认曲线。墙线、答案和收集星星使用相同的坐标变换，切换风格保留同一条路线。
- 默认开启极简模式，预览、PDF、图片和打印纸仅展示迷宫，隐藏标题、题号、说明、页脚和起终点文字/装饰；关闭后恢复完整练习纸。开关自动保存，旧配置首次升级也默认开启。
- 直接下载多页 A4 PDF（迷宫线条为矢量，中文标签内嵌为高分辨率图片，无字体依赖）。
- 下载当前预览页为 300 DPI PNG（2480 × 3508 像素）；查看答案时导出的是当前答案图。
- 浏览器直接打印使用专用 A4 页面；勾选「附上答案页」才会打印或导出答案，单纯查看答案不会泄露到练习纸。
- 自动保存当前配置及随机种子；更改纸张排版、线条风格、极简模式、标题、颜色和玩法不会改变已经生成的路线。
- 响应式布局、键盘操作、原生模态对话框、减少动画偏好。

## 打印建议

优先下载 PDF，选择 **A4、实际大小 / 100%、单面打印**。直接打印网页时关闭浏览器页眉页脚。不同难度通过路线长度、转弯和岔路区分，难度越高通道越密，挑战档四题排版的通道约 2 mm。切换每页题数时路线保持一致；六题排版更紧凑，完整模式精简每道题的说明与奖励区域。

形状使用原创几何轮廓，不依赖参考站的生成结果。细小部位会随网格简化；难度是相对档位，不代表经过儿童实测的年龄标准。

## 验证与部署

```sh
npm run check
npm test
npm run build
```

`dist/` 为可直接部署的静态文件，无需构建服务器。开发预览默认仅监听本机。

## 文件说明

- `js/shapes.js`：106 种轮廓、几何采样及形状缩略图。
- `js/lattices.js`：三角镶嵌、同心圆扇区、共享墙线与通道几何。
- `js/graph-maze.js`：几何迷宫生成树、边界出入口、答案与连通校验。
- `js/maze.js`：固定种子随机数、轮廓网格、生成树、求解、难度候选选择与结果校验。
- `js/geometry.js`：连续墙线追踪、圆弧转角、曲线网格与统一路线投影。
- `js/document.js`：共用 A4 场景、SVG 预览、PDF 和 PNG 导出。
- `js/app.js`：逐题设置、状态保存、分页和交互。
- `styles.css`：桌面、移动端及专用打印布局。
